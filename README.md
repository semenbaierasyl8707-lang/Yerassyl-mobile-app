# Yerassyl-mobile-app

Краткое описание проекта: Мобильное приложение на React Native и TypeScript, представляющее собой каталог сервисов и предложений с системой авторизации и личным кабинетом поддержки.

## 📱 Основной функционал

Приложение включает в себя полноценный пользовательский сценарий, состоящий из следующих ключевых экранов:

*   **Авторизация и безопасность:**
    *   Вход по номеру телефона и паролю (`LoginScreen`)
    *   Регистрация нового пользователя с проверкой формы и принятием условий соглашения (`RegisterScreen`)
    *   Восстановление пароля по SMS-коду (`ForgotPasswordScreen`, `VerifyScreen`, `ResetPasswordScreen`)
*   **Локализация:**
    *   Выбор городов Казахстана (Алматы, Астана, Шымкент и др.) для персонализации контента (`SelectCityScreen`)
*   **Контент и взаимодействие:**
    *   Главная страница — Каталог доступных сервисов и экспресс-опций с фильтрацией по категориям (`CatalogScreen`)
    *   Центр уведомлений для отслеживания системных событий и бонусов (`NotificationsScreen`)
    *   Центр поддержки пользователей с разделом FAQ и возможностью связи с оператором (`SupportScreen`)

## 🛠️ Стек технологий

*   **Фреймворк:** React Native (Expo)
*   **Язык программирования:** TypeScript
*   **Компоненты UI:** Custom-компоненты (Button, Input), StyleSheet
*   **Навигация:** Управление состоянием страниц внутри `App.tsx` (стейт-ориентированная навигация)

## 🚀 Архитектура проекта

Код разделен на модули и компоненты:
*   `App.tsx` — Корневой компонент приложения, координирующий переключение экранов и глобальное состояние.
*   `/src/screens` — Компоненты полноценных экранов интерфейса.
*   `/src/components` — Переиспользуемые элементы интерфейса (кнопки, кастомные поля ввода).
